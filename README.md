# hxyfront-62008 烟花燃放脚本编排 · 齐射编组台

源提示词编号：10

面向烟花燃放编排师的燃放脚本前端工具，支持节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点，提供时间轴编排、燃放点位平面图、型号清单、冲突时间提示和整场节目预览。

## 齐射编组规则

- **相邻并组**：平面图上多选（Shift / Ctrl + 点击）邻接阈值（默认 30m）内连通的点位并为一组，组内点火时刻完全一致，整组共用一个音乐时间点。
- **组间判定**：任两组按最近点位间距是否小于安全半径（取两组半径较大者）判定包络相交。
- **整组退回**：并组、删音乐点、组内任一节点调整时刻或角度，都会对整场编排重新判定；任一组包络相交或时刻对不上音乐点，操作整体退回，时间轴与点位图保持不动，并在冲突面板记录原因。
- **主控点位**：每组只留一个主控点位上时间轴，可在编组清单中切换；时间轴上每组仅主控点位一条。
- **本地存储**：点位、音乐点与编组只保存在浏览器 localStorage，不发送到任何服务端；可一键恢复演示数据。
